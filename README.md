# Sprint_7
Проект содержит автотесты API учебного сервиса [Яндекс.Самокат](https://qa-scooter.praktikum-services.ru/). Его [документация](https://qa-scooter.praktikum-services.ru/).

## Требования к проекту
1. Должны быть протестированы следующие ручки:
    - Создание курьера.
    - Логин курьера.
    - Создание заказа.
    - Список заказов.
2. В создание заказа должна быть использована параметризация.
3. Тесты должны быть независимыми.
4. Необходимые тестовые данные создаются перед тестом и удаляются после того, как он выполнится.

## Технологии, использующиеся в проекте
1. Java 11
2. Maven 3.9.9
3. JUnit 4.13.2
4. RestAssured 5.2.0
5. Allure 2.24.0
6. DataFaker 1.8.0
7. Lombok 1.18.30 (так же необходимо, чтобы Lombok плагин был установлен в вашей IDE. Для IntelliJ IDEA: Settings → Plugins → Lombok)

## Запуск тестов
Чтобы запустить тесты, выполните следующую команду в терминале:
```bash
mvn clean compile
mvn clean test
